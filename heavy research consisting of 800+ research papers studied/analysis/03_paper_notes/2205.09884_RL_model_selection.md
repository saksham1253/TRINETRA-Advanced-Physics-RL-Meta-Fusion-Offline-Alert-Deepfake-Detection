## Content (own words)
- Problem: no single anomaly detector consistently wins because real-time-series anomalies
  have diverse profiles matching different assumptions (low-frequency/EVT tails, density,
  forecast-residual, etc.).
- Core idea (re-implementable): learn a POOL of diverse base anomaly detectors, then use RL
  to DYNAMICALLY SELECT which base model to trust at each step/segment. The RL agent's reward
  encodes detection cost; experiments show it beats all individual baselines on overall
  performance.
- Evidence seen (Table III, reward ablation — directly useful numbers): tuning the
  false-negative vs false-positive penalty shifts precision/recall exactly as cost theory
  predicts: FN −1.0/FP −0.2 → P 74.69 / R 62.28 / F1 67.88; FN −1.2/FP −0.2 → P 79.30 / R
  61.46 / F1 69.12; FN −1.5/FP −0.2 → P 77.96 / R 61.54 / F1 68.70. I.e. heavier miss penalty
  raises precision but the recall/F1 trade-off is non-monotone — a cautionary data point.

## Relevance to us
- Component: GMF (gated meta-fusion = dynamic model selection) + WS8 anomaly + WS5 reward
  design. STRONG: this is cited prior art for RL-based model selection in our fusion head
  (alongside Meta-AAD). Takeaway: validates the GMF premise (select among base anomaly
  detectors via a policy) AND gives empirical evidence on how FN/FP reward ratios move
  precision/recall — directly informs our miss=−100 / FA=−5 reward calibration (the ablation
  warns that simply increasing the miss penalty does NOT monotonically improve F1).
- Conflict/caution: feeds the reward-design question (Q5.1) and warns against assuming a
  bigger miss penalty always helps — must be tuned + validated, not asserted.
- Transfer hypothesis: smart-grid/EVT time series ≠ multimodal hazard streams; selection
  framework transfers, numbers do not. confidence: high on method+relevance, med on transfer.
