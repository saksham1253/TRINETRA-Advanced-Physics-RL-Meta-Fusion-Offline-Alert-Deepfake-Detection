## Part 5: Download and attach cheat sheet (Hinglish)
1. Kaggle notebook kholo, then **Add Data**, search the slug (e.g. `phylake1337/fire-dataset`), and click Add. Data
   `/kaggle/input/fire-dataset/` par aa jayega.
2. Kaggle API (laptop): `pip install kaggle`, put the token in `~/.kaggle/kaggle.json`, then run
   `kaggle datasets download -d <slug> --unzip`.
3. Direct files: `wget <url>` (FIRMS, IBTrACS, Avenue zip).
4. Checksum: `sha256sum file > file.sha256`, and commit only the `.sha256` plus the manifest, **never the data**.
5. Build subset: `python data_adapters/build_npz.py ...` then `... check --npz <file>` (prints `[OK]` and the leak check).
