# 09d — TPD-0.1 data profiles

Profiles were generated by `data_adapters/profile_tables.py`; machine-readable outputs live in `data_manifests/profiles/`.

## Scope

Only tables that are real dataset inputs or registries are profiled. Paper ledgers and project-management CSVs are not TPD samples.

| table | rows × columns | exact duplicates | purpose |
|---|---:|---:|---|
| `docs/09b_dataset_links.csv` | 54 × 18 | 0 | source/link/license registry |
| `results/geo_large/geo_events.csv` | 736 × 22 | 0 | materialized landslide case-control pack |
| `results/geo_small/geo_events.csv` | 112 × 22 | 0 | earlier Chamoli-tile experiment; not separately indexed to avoid duplication |

## Large geo table

- 184 unique `event_id` values; 184 positive rows and 552 matched controls.
- Latitude 29.1585–32.7571; longitude 76.1201–80.3657.
- Labels are binary and complete. Slope, FS and dFS fields have no missing values.
- Spatial evaluation groups are not taken directly from `event_id`: code uses 0.1° latitude/longitude cells, producing 101 blocks.
- `day` has 525 unique values. Positive dates are catalog dates; controls are derived monsoon dates.
- Real source fields: catalog location/date, POWER rainfall and Copernicus DEM slope/elevation.
- Derived fields: rainfall windows, Caine ratio, pore-pressure response, FS, dFS, back-calculated cohesion and controls.

Hinglish: 736 rows ka matlab 736 independent landslides nahi hai. 184 real catalog events hain; har event ke saath teen derived control days hain. Isliye prevalence artificial hai aur accuracy headline sahi metric nahi.

## Small geo table

The 112-row table contains 28 positive events and 84 controls from a smaller tile. It is retained for audit, but TPD-0.1 uses the larger table only. Its positive physics advantage did not survive the larger evaluation.

## Missing inputs

Raw HMAGLOFDB rows, Landslide4Sense, Sen1Floods11 and Hephaestus are not committed. Therefore they have no TPD sample rows or profiles yet. Their source links and planned caps remain in `docs/09b_dataset_links.csv` and `docs/SMALL_GEO_DATASET_PACK.md`.

Reproduce:

```bash
python data_adapters/profile_tables.py \
  docs/09b_dataset_links.csv results/geo_large/geo_events.csv \
  results/geo_small/geo_events.csv --out-dir data_manifests/profiles
```
