**Teen layer har concept me:**
1. **Simple me samjho:** 3-6 Hinglish lines aur ek roz-marra ki misaal. Koi symbol nahi.
2. **Exact baat:** equation, symbol table (symbol, matlab, unit, range), assumptions, kab sahi aur kab galat.
3. **Parameters aur what-if:** code me jo value hai (file path), wo kahan se aayi, aur kam ya zyada karne par kya hoga.

**Claim ladder** (har comparison par): C0 not addressed · C1 design only · C2 implemented, untested on real data · **C3 implemented and measured by
us** · C4 matches a published result on a matched protocol. Abhi TRINETRA ke paas **koi C4 nahi** hai.

**Formula classes:** **A** established (paper + equation) · **B** team ne A se derive kiya ya data par fit kiya (steps shown) · **C** hypothesis
(code me default OFF). "Never done before" kabhi nahi likhte; novelty sirf "not verified".

**Number labels:** OUR RESULT (`results/` path) · PAPER REPORTS (paper, benchmark, metric) · TARGET (goal, result nahi) · WORKED EXAMPLE
(haath se ya code se calculate kiya, result nahi) · NOT FOUND IN REPO.
