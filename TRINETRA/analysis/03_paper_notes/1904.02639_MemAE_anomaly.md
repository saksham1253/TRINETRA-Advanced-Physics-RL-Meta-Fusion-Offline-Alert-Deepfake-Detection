## Content (own words)
- Problem it fixes: autoencoder anomaly detection assumes AEs reconstruct normal data well and
  anomalies badly — but AEs often "generalize" so well they ALSO reconstruct anomalies, causing
  MISSED detections (low recon error on true anomalies).
- Method: MemAE adds a MEMORY MODULE between encoder and decoder. Encoding is used as a QUERY to
  retrieve the most relevant memory items (prototypical NORMAL patterns learned during training);
  the decoder reconstructs from those few normal memory records. So any input — even an anomaly —
  gets reconstructed toward a NORMAL sample → anomaly reconstruction error is STRENGTHENED,
  improving detection. Memory is updated in training, fixed at test. Assumption-free re: data
  type → general (demoed on images/video/etc.). Fig.4: trained on "5", input "9" → MemAE output
  looks normal-"5"-like (large error), unlike plain AE which copies the "9".
