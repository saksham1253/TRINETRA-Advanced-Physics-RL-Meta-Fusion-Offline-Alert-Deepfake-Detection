## Problem & why it matters
This is the CLOSEST published analog to TRINETRA found so far: an operational, free-data-only,
multi-source ML flash-flood EWS for a data-sparse South-Asian basin (Sunamganj Haor, NE Bangladesh,
8,000 km², <12 working gauges), with a TRANSBOUNDARY upstream signal from INDIA (Barak River), SMS/
WhatsApp/email last-mile delivery in the local language, and a FULLY SEEDED public pipeline. It is
simultaneously a design template AND a methodological-honesty exemplar for us.

## Core idea / method (re-implementable sketch)
- Free inputs only: Sentinel-1 SAR (sees through storm cloud), rainfall records + forecasts, soil
  moisture, and a MODELED upstream Barak (India) signal worth ~36 h lead time.
- DESEASONALIZATION: subtract a monthly climatological anomaly to remove seasonal bias — cuts the
  temperature-label correlation from r=0.570 to r=−0.031 (i.e. prevents the model "learning the
  calendar instead of the flood"). THE key methodological lesson.
- Model: Random Forest + XGBoost ensemble (simple, interpretable — CR-02 aligned).
- Validation: leave-one-out cross-validation (LOOCV) over 77 real Sentinel-1 flood events (2014–2024).
- Alert + crop-damage modules; multi-channel delivery (SMS/email/WhatsApp) in Bengali.

## Key results (as stated)
- LOOCV: 90.9% accuracy, 89.2% F1, AUC 0.939 on 77 real-SAR events; labels cross-checked against
  12.3 years of official gauge records.
- Live run May–June 2026 (10 days): raised a high-risk alert ~3 days before the river neared danger
  level (real operational lead time).
- Deseasonalization ablation: temperature-label correlation 0.570 → −0.031 (removes the leakage).

## Assumptions & limitations
- Stated: tiny event sample (77 events), single basin; 6-page paper.
- Inferred: LOOCV over events can still leak if events are spatially/temporally correlated — but the
  gauge cross-check + live run strongly mitigate. "90.9%" is accuracy on an imbalanced problem →
  F1/AUC more meaningful (they report both — good practice).

## Relevance to TRINETRA
- component/workstream: whole-system analog — satellite layer (Sentinel-1), fusion (RF/XGBoost),
  transboundary upstream signal, last-mile delivery, impact (crop-damage) module.
- actionable takeaway: (1) DESEASONALIZE every seasonal input (temperature, baseline flow) via monthly
  climatological anomaly BEFORE training — otherwise the model learns the calendar; add as a mandatory
  preprocessing step + leakage check (report feature-label correlation before/after) — this is a NEW,
  concrete anti-leakage procedure for our pipeline; (2) a MODELED upstream signal from across the
  border (for us: upstream Himalayan catchments / Nepal / China Tibet) can buy ~1.5 days lead — design
  the transboundary signal explicitly (research-note: data-sharing/legal flag); (3) RF/XGBoost ensemble
  + Sentinel-1 is a credible, cheap, honest baseline that WORKS operationally (CR-02); (4) report LOOCV
  over EVENTS (not random split) + cross-check labels against independent gauge records; (5) last-mile
  multi-channel local-language delivery + an impact module (crop/people) are first-class system parts,
  not afterthoughts (ties E-07 people-at-risk, T3 human response).
