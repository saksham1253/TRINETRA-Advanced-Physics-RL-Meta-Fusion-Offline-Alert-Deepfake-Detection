## Content (own words, from abstract)
- Problem: LoRa is low-power + long-range but underperforms in RURAL settings due to
  transmission/reception conditions. Goal: find optimal LoRa configs for HILLY/MOUNTAINOUS
  terrain in Nepal.
- Method: LoRa MESH network; sweep physical-layer params Bandwidth (BW), Spreading Factor (SF),
  Coding Rate (CR); measure RSSI, SNR, packet loss; discuss propagation loss vs param changes.
  Hardware: Arduino Uno + ESP32 + LoRa modules, transmitter/receiver nodes, a SELF-BUILT
  monopole antenna reported to beat commercial options on gain. Also integrates data to cloud
  (ThingSpeak) as an IoT backbone. Ends with RECOMMENDED param values for Nepal hilly/mountain
  terrain + the trade-offs of each.
