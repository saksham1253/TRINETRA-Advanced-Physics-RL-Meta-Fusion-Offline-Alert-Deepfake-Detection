## Problem & why it matters
Forecasting FUTURE InSAR ground deformation from sparse Sentinel-1 time series — the exact precursor
signal TRINETRA's satellite layer must forecast for slow-moving landslide/subsidence hazards. Also a
clean CR-02 instance: the paper's own interpretability analysis shows the ML BASELINES default to
PERSISTENCE, which both validates persistence as a mandatory baseline and shows where a spatio-temporal
model actually adds value.

## Core idea / method (re-implementable sketch)
- Transform SPARSE InSAR point measurements into a DENSE spatio-temporal TENSOR → enables standard
  CV architectures to be applied to deformation forecasting (the methodological contribution).
- Model: hybrid CNN-LSTM (CNN spatial + LSTM temporal), single-step-ahead forecasting, input window
  T_in = 300 steps.
- Baselines: LightGBM and LASSO regression. Metrics: regression (R², error) + classification framing;
  SHAP (TreeExplainer) for feature importance / interpretability.
- Sentinel-1 data, eastern Ireland.

## Key results (as stated)
- CNN-LSTM gives more accurate + spatially coherent forecasts than LightGBM / LASSO ("new benchmark").
- INTERPRETABILITY finding (load-bearing): baseline models often DEFAULT TO SIMPLISTIC PERSISTENCE
  (predict last value) — the authors use this to argue the integrated spatio-temporal model is
  necessary to capture real dynamics. I.e. you MUST beat persistence, and simple models often don't.

## Assumptions & limitations
- Single region (eastern Ireland), urban/geologic subsidence not Himalayan landslides. Single-step
  forecasting only (not multi-horizon). Sparse→dense tensor interpolation introduces its own
  assumptions. Preprint.
