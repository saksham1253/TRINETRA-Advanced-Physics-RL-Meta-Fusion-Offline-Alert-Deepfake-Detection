## Content (own words)
- Problem: DGPS/RTK gives cm-level outdoor localization but base stations + receivers are
  normally expensive.
- Core idea (re-implementable, hardware recipe): build a ROS-enabled LOW-COST DGPS using
  third-party open-source software + a u-blox ZED-F9P chip, ready in a few hours. Evaluate
  repetitive + absolute accuracy; compare a SAPOS (national network) base station vs a
  locally-installed low-cost base; absolute accuracy measured on a moving robot tracked by a
  VICON motion-capture ground truth; corrections via NTRIP.
- Known general facts stated: plain GPS ~ several metres; DGPS/RTK ~ a few centimetres.
  (Exact measured cm figures are in the pruned tables — NOT verified here.)

## Relevance to us
- Component: WS7 (IoT ground node) + HARDWARE_BUDGET. STRONG practical relevance: TRINETRA's
  ground-deformation/tilt nodes need cm-level displacement sensing to catch slow slope creep;
  the u-blox ZED-F9P low-cost RTK recipe is a credible, documented path to that at low cost.
  NTRIP + a local low-cost base vs national CORS is exactly the deployment choice we'll face
  in Uttarakhand/Himachal (where CORS/NTRIP coverage is sparse → local base may be needed).
