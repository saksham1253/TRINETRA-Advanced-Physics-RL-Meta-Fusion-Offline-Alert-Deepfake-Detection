## Content (own words)
- Systematic mapping of 21 primary studies on Technical Debt (TD) in AI/ML systems. Findings:
  (i) established software TD types appear PLUS FOUR NEW AI-specific TD types — **data debt,
  model debt, configuration debt, and ETHICS debt**; (ii) 72 antipatterns catalogued, most about
  DATA and MODEL deficiencies; (iii) 46 proposed solutions. Most-referenced antipattern:
  **training/serving skew** (train-time pipeline differs from serving pipeline) among others.
- Core message: ML systems are software systems but with distinctive risk sources (data quality
  dominates, fuzzy abstraction boundaries, hard component reuse) → they accrue hidden debt that,
  unmanaged, becomes reliability/safety risk over time.
