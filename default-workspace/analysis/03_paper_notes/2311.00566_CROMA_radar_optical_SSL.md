## Content (own words, from abstract)
- Problem: remote sensing has vast, SPARSELY LABELED, spatially-aligned MULTIMODAL data →
  self-supervised learning is invaluable.
- Core idea: CROMA combines CONTRASTIVE + RECONSTRUCTION SSL objectives. It separately encodes
  masked multispectral OPTICAL and SAR samples (aligned in space + time), does CROSS-MODAL
  contrastive learning, then a fusion encoder produces joint multimodal encodings used to
  predict masked patches via a lightweight decoder. Introduces X-ALiBi + 2D-ALiBi (spatial
  attention bias) enabling test-time extrapolation to images up to 17.6× larger.
- Evidence (abstract-verbatim): beats prior SoTA multispectral model — classification:
  finetune +1.8%, linear probe +2.4%, nonlinear +1.4%, kNN +3.5%, K-means +8.4% (avg); 
  segmentation +6.4% (avg across 3 benchmarks).
