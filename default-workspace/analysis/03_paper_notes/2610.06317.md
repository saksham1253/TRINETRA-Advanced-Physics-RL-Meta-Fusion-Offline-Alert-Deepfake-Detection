## What it is
A rigorous treatment of the gap between what regulation (EU AI Act **Article 50(2)**: synthetic outputs
must be machine-readable + detectable) DEMANDS and what watermarking can ACTUALLY deliver. Core honesty
move: **strong watermarking is IMPOSSIBLE against adaptive removal**; ordinary edits attenuate
statistical evidence; unmarked human text can distributionally overlap machine text. So instead of
claiming robustness, it builds an **AUDITABLE alternative**:
1. **Description-length robustness profile:** a finite-sample bound showing detectable bias DECAYS and
   required sample size grows with the INVERSE SQUARE of the decay rate; replaces an unidentified
   Shannon-entropy constant with **collision entropy** (identifiable).
2. **Label-conditional conformal prediction sets** with SEPARATE false-attribution and false-exclusion
   levels, reporting one of **"watermark supported" / "not supported" / "inconclusive."** Coverage is
   finite-sample, class-conditional under exchangeability.
3. **Operationalizes compliance** as a premarket certificate + signed detector report + postmarket
   recalibration protocol — WITHOUT claiming universal robustness.
- Reproducible simulation of a tournament watermark confirms the bounds and shows the common
  **"surviving-token" rule OVERSTATES the tolerable edit rate roughly TWOFOLD.**

## Why it matters to TRINETRA (WS2/WS3 provenance doctrine + the honest-UQ spine + Rule 19/§0.5)
- **Capstone of the media-provenance cluster.** With PWS-spoofing (2604.24404), C2PA soft-binding
  fragility (2610.04151), and interpretable deepfake (2610.03380), this paper supplies the PRINCIPLE:
  **you cannot certify authenticity robustly; you can only produce an AUDITABLE, calibrated, three-way
  verdict with explicit error levels.** → TRINETRA's handling of any provenance/authenticity signal
  (crowd images, CCTV, forwarded alerts) must output **supported / not-supported / INCONCLUSIVE**, never
  a binary "real/fake," and must be a confidence modifier, never a sole gate (reinforces RB-16).
- **Methodological transfer to our WS8 UQ layer:** the **label-conditional conformal set with separate
  false-attribution vs false-exclusion levels** is exactly the asymmetric-error framing we need for
  alerts (false-alarm cost ≠ miss cost; Bayes p*=C_FA/(C_FA+C_miss)). It is a concrete pattern for
  reporting "alert supported / not supported / inconclusive (abstain to human)" — ties the conformal
  abstention design (EnbPI/DistMatch) + the cost-loss Value Score + the human-in-loop requirement.
- **Impossibility-honesty reinforces §0.5:** just as strong watermarking is impossible, we must NOT
  claim hard guarantees (conformal coverage is approximate under stability; FoS is a gate not a
  probability; no claims about our own system until built). "Auditable compliance without claiming
  universal robustness" is the exact posture for a life-safety system under Rule 19.
- **Regulatory-architecture template:** premarket certificate + signed report + postmarket
  recalibration maps onto our "design doc → acceptance gates → live-drift recalibration" lifecycle.
