## Content (own words)
- Problem: EO datasets are atomised (diverse formats/structures) → hard to combine, effort
  duplicated, models trained on small static dumps.
- Core idea: Major TOM (Terrestrial Observation Metaset) = an EXTENSIBLE framework = a
  geographic grid-point indexing system + a metadata structure that lets datasets from
  different sources be merged interoperably. Ships MajorTOM-Core: >2 trillion pixels of
  Sentinel-2 covering nearly all Earth land, open-access on HuggingFace (huggingface.co/
  Major-TOM). Acts as both resource and template for future additions.
