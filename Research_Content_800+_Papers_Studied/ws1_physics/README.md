# Workstream directories (MASTER_PROMPT §0.10)

Design docs, specs and plans for each workstream are written in their phase and stored in
the matching `wsN_*/` folder. Index:

- `ws1_physics/`  — slope stability, infiltration, I–D thresholds, runout (Phase P7).
- `ws2_deepfake/` — media forensics / misinformation on alerts (Phase P11).
- `ws3_alerting/` — CAP/SACHET routing, DTN dissemination, decision/evacuation (P3/P13/P15).
- `ws4_cctv/`     — River-Eye LSPIV + CCTV video anomaly detection (Phase P8).
- `ws5_rl/`       — offline/safe RL alarm policy + gated meta-fusion head (Phase P15).
- `ws6_robustness/` — conformal, OOD, drift, calibration (Phase P14).
- `ws7_iot/`      — ₹2000 LoRa node, sensors, energy, comms (Phase P6).
- `ws8_anomaly/`  — SSL encoder, forecast-residual, Deep SVDD anomaly stack (P9/P10).

This README is the only P0 content; folders fill up in their phases.
