## Content (own words)
- Problem: phishing detectors are mostly statistical ML classifiers — they lack CONTEXTUAL
  reasoning, are brittle to adversarial/obfuscated inputs, and their FALSE ALARMS are triaged by
  human analysts, causing ALERT FATIGUE that erodes human oversight. Retraining to absorb new
  attack patterns is expensive.
- Method: a HYBRID framework — standard ML classifier + a POST-HOC non-monotonic reasoning layer
  in Answer Set Programming (ASP). A CONFIDENCE-GATED defeasible rule revises a prediction only
  when (a) extra context (website metadata) is present AND (b) the classifier is LOW-CONFIDENCE;
  high-confidence predictions are left alone, uncertain ones are deferred/revised using expert
  knowledge (formal belief revision).
- Verified results (abstract): the reasoning module modifies 5.08% of classifier outputs →
  improved decision consistency; new domain knowledge can be added to the reasoning layer in
  O(n) time, with NO model retraining.
