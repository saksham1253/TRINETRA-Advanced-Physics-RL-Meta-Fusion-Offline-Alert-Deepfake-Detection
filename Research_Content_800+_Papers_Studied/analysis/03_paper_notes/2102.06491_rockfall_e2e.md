## Content (own words)
- Problem: rockfall detection from point-cloud (Terrestrial Laser Scanner) / imagery is done
  near-manually via tedious multi-temporal visual comparison → inaccurate, expert- and
  sensor-dependent.
- Core idea (re-implementable): an end-to-end ML framework that detects rockfall CLUSTERS in
  point-cloud data. Because the problem is EXTREMELY IMBALANCED, it systematically benchmarks
  many pipeline combinations = {resampling technique × model × feature-selection}, compared
  with proper statistics (Friedman + Nemenyi critical-difference test, Eq.2: CD = q_α·
  sqrt(n_models(n_models−1)/(6n))). Two Spanish case studies (basaltic cliff Castellfollit de
  la Roca; conglomerate Montserrat Massif).
- Findings: certain pipelines detect rockfall on mountain walls with experimentally proven
  accuracy; emphasis on rigorous imbalanced-classification methodology + statistical model
  comparison rather than a single model claim.

## Relevance to us
- Component: WS4 (geohazard detection) + methodology. Takeaway TWO things: (1) a concrete
  template for EXTREME CLASS IMBALANCE handling (resampling benchmarks) — core to every
  TRINETRA hazard task; (2) the Friedman/Nemenyi critical-difference protocol is exactly the
  rigorous multi-model comparison we should adopt in P15 (don't declare a winner without a
  significance test). Reinforces 2608.12422's "beat the baseline, prove it" discipline.
- Transfer hypothesis: TLS point clouds ≠ our satellite/CCTV modalities; the IMBALANCE +
  STATISTICAL-COMPARISON methodology transfers directly, the specific features do not.
- confidence: high on methodology relevance; low on direct feature transfer. Feeds P15
  evaluation protocol + the imbalance theme (A8).
