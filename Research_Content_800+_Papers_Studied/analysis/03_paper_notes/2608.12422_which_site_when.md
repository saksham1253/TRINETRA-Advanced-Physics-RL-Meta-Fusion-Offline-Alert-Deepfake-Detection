## Content (own words)
- Problem: predict WHICH Himalayan site is susceptible and WHEN a trigger arrives, for three
  hazards (moraine/ice-dam bursts, rainfall landslides, small glacier-pond floods), using
  FREE satellite data only. Two questions per hazard, never blended.
- Data: 589 dated outbursts (HMAGLOFDB) + several thousand catalogued landslides; each event
  MATCHED against similar-but-unfailed sites (case-control) to remove background confounding.
- Method (re-implementable core): hold every model to a STRONG SIMPLE BASELINE under SPATIAL
  cross-validation that WITHHOLDS WHOLE MAP TILES, so no model wins by memorizing a trained-on
  neighbourhood. Feature-deletion honesty check: if (roc − roc_ablated) <= 0.02 the model
  wasn't really using its "important" features and the attribution is not believed.
- Results (verified numbers): antecedent-weather TIMING ROC 0.73 big bursts / 0.83 landslides
  / 0.82 small floods. Susceptibility: naive ~0.90 but inflated (failures cluster in wetter
  ranges); HONEST matched figures 0.76 / 0.71 / 0.54 (last = chance). Burst signal reaches
  0.89 within Nepal alone (single region). FIVE deep-learning models do NOT decisively beat a
  gradient-boosted baseline; for lake hazards the baseline WINS, reproduced by a 3-RULE
  decision tree on ruggedness + monsoon rainfall. Deliverable = ranked Nepal watchlist, a
  PRIORITISATION AID, explicitly NOT a prediction.
