## The core problem it names (THE takeaway for us)
Time-Series Foundation Models (TSFMs) are trained to reconstruct/forecast broad temporal patterns.
That strength is a **weakness for anomaly detection**: a TSFM may reconstruct/forecast **anomalous
patterns just as well as normal ones**, so the reconstruction/forecast error (the anomaly score)
**shrinks for anomalies too** → anomalies hide. This is a fundamental failure mode of
error-based anomaly scoring with powerful models.

## The method (NCL)
Plug-and-play, **does not modify pretrained params**:
- **NormSpace:** build a compact normal subspace from a few normal patch features via few-shot SVD.
- **PatchNT:** lightweight patch-adaptive transformation W_i = I − β_i v_i v_iᵀ (Householder-like
  reflection; a Proposition characterizes its spectrum) that steers each patch feature toward the
  normal subspace.
- **ConNC:** contrastive constraint forming compact, discriminative normality manifolds.
- Calibrated features fused with original TSFM output → amplifies normal-vs-abnormal discrepancy for
  error-based scoring. Reported to consistently improve AD across TSFM families + benchmarks.

## Why it matters to TRINETRA (WS8 anomaly / WS1 forecast-residual)
- **Our anomaly layer is forecast-residual + Deep SVDD + isolation forest + XGBoost.** The
  forecast-residual branch is EXACTLY the design NCL warns about: if we ever use a powerful
  pretrained forecaster for InSAR/river/rain residuals, it may **learn to predict the precursor/
  anomaly itself**, collapsing the residual right when a hazard builds — a silent, dangerous failure
  (Rule 19). ADD to FM catalogue as a new failure mode.
- **Design implications:**
  1. Keep the forecaster **constrained to normal dynamics** (train only on quiescent periods;
     NCL's "normal subspace" idea), OR cap model capacity so it can't fit precursors.
  2. Always pair forecast-residual with a **model-free** detector (Deep SVDD / isolation forest) and
     the physics gate, so no single powerful model can mask the signal.
  3. Monitor residual-score DISTRIBUTION over time — a shrinking residual variance near a known
     precursor is itself a red flag.
- NCL itself (few-shot normal subspace + contrastive) is a candidate WS8 enhancement — build-phase
  option only.
